## Continuity in one paragraph

Commanded stops, low-PWM stops and stalls are one event to navigation: the
magnetic waveform stops developing, then resumes.
- Every 20 ms block passes through a 1 s delay line (50 blocks).
- A block that lies in a flat 1 s span (range of 24 ADC or less) **and** off the
  baseline (more than 16 × baseline noise) is a stationary repetition and is
  withheld.
- Everything else reaches the recognizer, in order. On the baseline nothing is
  ever withheld.
- An unfinished ensemble, its baseline and the held candidate therefore survive
  any stop or stall, and continue when the tracing develops again.
- PWM and the commanded target are not read by navigation.
- There is no backlog: one block in, at most one out.

## What changed for the operator and the Pi

| | NAVI_RVM_SHAPE_MANUAL (`3a8953c`) | NAVI_RVM_CONTINUITY_MANUAL |
|---|---|---|
| `state/bootid` sketch | `NAVI_RVM_SHAPE_MANUAL` | `NAVI_RVM_CONTINUITY_MANUAL`, `"continuity":"HALL_ONLY_K50_B24_M16"` |
| Declaration takes effect | immediately | at its block leaving the 1 s delay line (about 1 s later); `DECLARED` is reported then |
| `diag/rvm_stopgo` | `STOPPED_WAVEFORM_PAUSED` / `PATTERN_RESUMED` | `DEVELOPMENT_STOPPED` / `DEVELOPMENT_RESUMED`, with `hall`, `baseline_level`, `baseline_noise`, `withheld_run_blocks`, `withheld_total` |
| `state/nav` | `waveform_paused` | `withholding` |
| `state/loopstat` | `paused_blocks`, `rvm_backlog`, `rvm_backlog_max` | `withheld_blocks`, `continuity`, `rvm_delay_blocks` |
| Reporting delay | 0 s, up to minutes after a commanded stop | a constant 0.98 s |

Manual throttle, brake, STOP, E-STOP, direction, battery protection, MQTT and
the Pi NAVI sync recording are unchanged.

## Build (compile only)

```sh
tools/navi_rvm_continuity/build.sh --credentials-dir DIR --build-path BUILD   # DIR/credentials.h is your private file
```

## Verify without hardware

```sh
tests/navi_rvm_continuity/run_checks.sh
```

This runs the unit checks and the authority check, and builds the replay. The
recording replays and parity check are
`analysis/navi_rvm_shape_20261018/unified/u10_firmware_parity.py`.

## Generated file

`RvmShapeModel.h` is generated by
`analysis/navi_rvm_shape_20261018/scripts/s13_export_model.py`. It is identical
to NAVI_RVM_SHAPE_MANUAL's copy. Do not edit it by hand.
