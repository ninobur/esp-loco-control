## Clean-sheet proposal discrepancies

1. **Baseline classification:** Calling the entire baseline architecture “unresolved” is inaccurate. The source establishes spatial/inter-magnet collection and the longer intervening segment’s median. Exact collection, promotion, persistence, and stopped behavior remain unresolved. This is a documentation omission, not permission to choose a time-based substitute.
2. **Shape authority:** Any clean-sheet component using Gaussian, line-versus-curve, or morphology score as a reject gate is an incorrect interpretation of the later explicit agreement. Such scores may log/diagnose/calibrate.
3. **Observation versus motor/geographic authority:** A recognizer may not let an unqualified observation halt observation or mutate location. Motor hold is boundary-only NAVI authority; other host motor authority must be audited separately.
