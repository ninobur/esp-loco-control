# NAVI Power of Normal — Reconciled Governing Specification

**Authority:** derived from `NAVI_TWENTY_ORIGINAL_AGREEMENTS_20261024.md`. Later explicit amendments control.

| ID | Requirement | Status |
|---|---|---|
| REC-01 | Automatic NAVI has declared position, direction, and one mapped next target. | Established |
| REC-02 | Cycle is **Expect → Observe → Qualify → Confirm/Advance**. | Established |
| REC-03 | Only a qualified expected target advances geography, exactly one marker. | Established |
| REC-04 | No alternative-ID search, skip, recovery, or timing-only passage inference. | Established |
| REC-05 | Hall observation is continuous and independent of target judgment; observer has no geographic authority. | Established |
| REC-06 | 70×2 opening captures opening polarity; qualification occurs after observed completion. | Established |
| REC-07 | Correct polarity, minimum physically plausible width, observed completion, and expected geography are necessary qualifications. | Established; values/conventions open |
| REC-08 | General waveform shape (Gaussian/bell/residual/template/lobe score) is diagnostic only; it cannot veto an otherwise qualified target. | **Amended / established** |
| REC-09 | Wrong polarity is nonqualifying: retain last confirmation and keep looking for same target. | Established |
| REC-10 | Baseline is spatial/inter-magnet ordinary-track evidence; the longer intervening segment supplies a median. | Established |
| REC-11 | Exact baseline eligibility, collection/promotion, return band, persistence, and stopped behavior remain evidence-backed implementation questions. | Unresolved |
| REC-12 | Elapsed time/PWM history support plausibility only; IR is excluded from Hall-only decisions. | Established |
| REC-13 | Only expiry of a validated per-interval, pace-normalized arrival boundary requests stop-and-hold; Hall observation continues. | Established; numerical method open |
| REC-14 | Three-sigma, a universal timeout, fixed quiet-time baseline surrogate, morphology veto, recovery engine, and hypothesis list are not authorized. | Established exclusions |
| REC-15 | Each implementation mechanism requires approved requirement + demonstrated need; ambiguity returns to the conference. | Established |
| REC-16 | Host audit and historical replay precede integration. | Established |

Observation → interpretation → navigation decision → motor authority are distinct.
