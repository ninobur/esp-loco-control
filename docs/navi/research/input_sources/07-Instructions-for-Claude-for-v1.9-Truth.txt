uint32_t physicalMagNo = 0;       // increments on every detected Hall event

uint32_t totalMmPosition = 0;     // ordinaryMmNo + inferredMmNo

On every Hall event:

* If class is MILE, increment ordinaryMmNo and update totalMmPosition.
* If class is MISSED_MM_1, infer one missing ordinary MM space.
* If class is MISSED_MM_2, infer two missing ordinary MM spaces.

enum NavConfidence {

    CONF_LOCKED,
