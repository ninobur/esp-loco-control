## Method

The canonical `transcript.jsonl` was parsed as JSONL. Retained messages have top-level type `user` or `assistant`, text content, original timestamp, and UUID. Internal system prompts, tool calls/results, API payloads, local paths, model signatures, and session-control records are excluded from the repository transcript.
