# CTO3 design record

This directory preserves the evidence and current intent for CTO3, the future
Lowline autonomous-operations architecture.

- `CTO3_INTENT_BASELINE.md` states the current design intent. It is the entry
  point for future CTO3 design work.
- `resources/` contains source material that led to the baseline.
- `resources/README.md` explains provenance, authority, sanitization, and which
  historical ideas have been superseded.
- `resources/MANIFEST.csv` records hashes for the repository copies.

These documents do not authorize implementation changes to QUORUM or current
firmware. Historical material is evidence, not automatically a current
requirement.
