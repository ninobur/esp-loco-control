Candidate `d18fe67e52deda91720be4384cd77c8f53c62cf0`. All source links are pinned to this commit. Read with the [report](REPORT.md), [requirements](ARCHITECTURE_RECONCILIATION.md) and [dependency map](BEHAVIORAL_DEPENDENCY_MAP.md).

The authority keys A/M/X/D23/U/H120/H121/H122/H6 are defined in the report. **Required** means the mechanism implements established intent; it does not certify its numerical choices or field performance. **Supporting** has no separate operating entitlement. **Legacy** means inherited authority not fully reconciled under RVM. **Contradictory** means a source-established inconsistency. An absent requirement is reconciled separately.

Effect tags explicitly answer the audit questions: **G+** can advance MM; **G−** can suppress/freeze advancement; **R** changes an origin, reference or interpretation; **P** changes PWM/direction; **S** controlled stop; **E** E-STOP; **U** withdraws AUTO; **D** requires or performs declaration; **T** affects station timing/landing. “None” means no direct control effect; resource or external-output qualifications are stated. Reachability paths abbreviate actual callers, not inferred symbol presence.

## Complete mutation and terminal-path check

The source has two legitimate MM mutation doors: explicit `declare` and a non-final/non-stop RVM token (`NaviIntegratedCore.h:60–67,193–197`). Numerical phase, IR offset, station selection and timers do not independently increment MM. Token/log queue overflow does not undo a committed MM.

Actual motor output has these doors: `serviceRamp → writePwm → ledcWrite`, direct tile entry/timed PWM in `serviceAutoCruise → writePwm`, and startup PWM-low/halt. Direction output is the motor-direction variable written by stopped manual command, applied in `serviceRamp`/setup. All stop/withdraw paths above converge on those doors; there is no hidden speed governor or old DART actuator path.

The complete set of declaration-forcing runtime latches is: RVM loss of pattern, RVM stall, timing-history failure, direction-context change and PWM-zero displacement. Generic `withdraw` alone clears enrollment and publishes nav_ready zero but does not create a new geographic stop latch. Ordinary station dwell, operator STOP, auto0, dispatcher release, external E-STOP release and recovered voltage do not themselves call `declare` or reset the recognizer.
