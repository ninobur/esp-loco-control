## Findings (recorded; no change proposed)

1. **A refused declaration is easy to miss.** The refusal was published as a
   `state/warning`, the operator set the direction, and the run proceeded
   for 22 minutes without a position.
2. **IR coupling defaults to OFF after every boot** (`irCarCoupled=false`,
   "operator-confirmed, deliberately not persisted"). On boot
   `EE765AA21A71C703` (runs 1–4c) it had been set to 1 before the captures
   began; on this boot it was never set. In this build coupling affects only
   the IR speed telemetry: `ir_speed_reason:"COUPLING_UNCONFIRMED"`,
   `ir_speed_authority:"OBSERVE_ONLY"`. The `ir_coupled` handler is
   documented "Display qualification only; no motor or navigation changes".
   It does not gate IR distance windows, recovery or stations.
   - **Operator design proposal (David):** "Physical IR coupling is the
     normal configuration. After reboot, requiring the operator to affirm 'IR
     coupled' creates an easy omission. Proposed UI semantics: coupled should
     default ON; operator explicitly selects uncoupled when the IR car is
     intentionally absent." Recorded for decision; not implemented.
